# Changelog

All notable changes to Unstop Autopilot will be documented in this file.

## [0.1.0] - 2024-11-08

### Added
- Project scaffold with modular architecture
- SQLite database with SQLAlchemy ORM (14 tables)
- Ollama LLM client with health checks and structured JSON output
- Playwright-based opportunity discovery from Unstop public listings
- Rich terminal dashboard with system status, statistics, and opportunity listing
- Configurable CSS selectors for web scraping resilience
- Security policy engine with approval levels
- Environment-based configuration (.env)
- Comprehensive .gitignore for data privacy
